Adds this repo's pstack verifier: docs/feature-map.md, verifier/start-app.sh, verifier/drive.mjs, verifier/verify.mjs, its offline tests, and .github/workflows/pstack-verifier.yml. The verifier runs the app on the base and head commits in two local checkouts and compares. The owner decided on 2026-11-15 that the verifier on GitHub is DeepSeek, for every author: `author-model: claude`, `openai`, `grok` and `deepseek` all get the DeepSeek verifier, a missing `author-model` line counts as DeepSeek, and any other value fails closed. A same-family run says so in one line of the PR comment. The Claude agent path stays in the code but the table does not reach it, so the workflow installs Pi only and no Claude login is needed. The DeepSeek family runs the Pi coding agent (`@earendil-works/pi-coding-agent`, pinned) as `pi -p --provider opencode-go --model deepseek-v4.1-flash` with the prompt on stdin and login `OPENCODE_API_KEY`; never the OpenCode app and never a CLI with a DeepSeek endpoint. The DeepSeek path is unproven until one real run passes.
