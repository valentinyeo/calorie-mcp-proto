Adds this repo's pstack verifier: docs/feature-map.md, verifier/start-app.sh, verifier/drive.mjs, verifier/verify.mjs, its offline tests, and .github/workflows/pstack-verifier.yml. A verifier from another model family runs the app on the base and head commits in two local checkouts and compares. DeepSeek is the default verifier family; Claude verifies only a DeepSeek author, and a missing `author-model` line counts as DeepSeek. The DeepSeek family runs the Pi coding agent (`@earendil-works/pi-coding-agent`, pinned) as `pi -p --provider opencode-go --model deepseek-v4.1-flash` with the prompt on stdin and login `OPENCODE_API_KEY`; never the OpenCode app and never a CLI with a DeepSeek endpoint. The DeepSeek path is unproven until one real run passes.
